## 2. 告别 asm.js：Mozilla 宣布停止支持

**来源：** SpiderMonkey Blog | [原文链接](https://spidermonkey.dev/blog/2026/05/20/saying-goodbye-to-asmjs.html)

Mozilla 宣布将逐步淘汰 asm.js，这是早期用于在浏览器中运行高性能代码的 JavaScript 子集。随着 WebAssembly 的成熟和普及，asm.js 已无必要，此举将推动开发者全面转向 WebAssembly。

> 💡 影响前端性能优化和 Web 游戏/应用开发的技术选型，标志着一个时代的结束。
