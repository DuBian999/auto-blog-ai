## 3. Astro 6.4 发布：引入 Rust 驱动的 Markdown 处理器

**来源：** Astro Official | [原文链接](https://astro.build/blog/astro-640/)

Astro 6.4 推出了可插拔的 Markdown 处理器 API，并附带一个基于 Rust 的 Markdown 处理器，可显著加快构建速度。同时，该版本还增加了对 Cloudflare 高级路由的实验性支持。

> 💡 Astro 是内容驱动型网站的首选框架，Rust 处理器的引入将大幅提升大型文档站点的构建性能。
