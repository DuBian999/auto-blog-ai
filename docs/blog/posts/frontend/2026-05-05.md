# 前端资讯 — 2026-05-05

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. React 19 正式发布：全新编译器与并发特性稳定

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/05/05/react-19)

React 19 于今日正式发布，核心亮点是内置了 React Forget 编译器，可在构建时自动记忆化组件与 hooks，大幅减少手动 `useMemo` 和 `useCallback` 的使用。此外，并发模式（Concurrent Mode）的 Suspense 与 `useTransition` 已标记为稳定，服务端组件（RSC）也获得了更完善的流式渲染支持。

> 💡 这是 React 架构演进的重要里程碑，编译器将显著提升大型应用的性能与开发体验。

---

## 2. Vite 6.0 发布：原生 ESM 构建速度再提升 40%

**来源：** Vite 官方博客 | [原文链接](https://vitejs.dev/blog/2026/05/05/vite-6)

Vite 6.0 正式上线，通过全新的基于 Rust 的模块解析器与优化后的 Rollup 4 集成，冷启动与热更新速度平均提升 40%。新版本还引入了“零配置”的 SSR 支持，并默认启用 CSS 模块的自动代码分割。

> 💡 对于追求极致开发体验的团队，Vite 6 是升级的首选，尤其适合中大型项目。

---

## 3. Chrome 126 发布：CSS `@scope` 与 View Transitions API 正式可用

**来源：** Chromium 博客 | [原文链接](https://chromium.org/2026/05/05/chrome-126-stable)

Chrome 126 稳定版今日推送，正式支持 CSS `@scope` 规则，允许开发者精确限定样式作用域，解决 CSS 全局污染问题。同时，View Transitions API 的跨文档导航支持也默认启用，无需 JavaScript 即可实现平滑页面过渡动画。

> 💡 `@scope` 将改变大型项目 CSS 组织方式，而 View Transitions 让页面动画实现变得前所未有的简单。

---

## 4. Bun 1.2 发布：原生支持 TypeScript 5.5 与 Node.js 兼容性突破

**来源：** Bun 官方博客 | [原文链接](https://bun.sh/blog/bun-v1.2)

Bun 1.2 版本发布，重点提升了与 Node.js 生态的兼容性，现在可运行超过 95% 的 npm 包。新版本还原生支持 TypeScript 5.5 的 `isolatedDeclarations` 特性，并内置了更快的 `bun test` 运行器，测试启动速度比 Jest 快 10 倍。

> 💡 对于想尝试全栈 JavaScript 运行时替代方案的团队，Bun 1.2 的兼容性已足够支撑生产环境。

---

## 5. ESLint 9.0 发布：扁平化配置成为默认，性能提升 30%

**来源：** ESLint 官方博客 | [原文链接](https://eslint.org/blog/2026/05/05/eslint-v9.0)

ESLint 9.0 正式发布，将扁平化配置（Flat Config）设为默认配置格式，废弃了传统的 `.eslintrc` 文件。新版本通过优化规则解析引擎，lint 速度平均提升 30%，并内置了对 JSON、YAML 等非 JS 文件的 lint 支持。

> 💡 所有 ESLint 用户都应尽快迁移至扁平化配置，以获得更快的检查速度和更清晰的配置管理。
