## 1. Bun 1.2 发布：原生支持 TypeScript 5.5 与 Node.js 兼容性突破

**来源：** Bun 官方博客 | [原文链接](https://bun.sh/blog/bun-v1.2)

Bun 1.2 版本发布，重点提升了与 Node.js 生态的兼容性，现在可运行超过 95% 的 npm 包。新版本还原生支持 TypeScript 5.5 的 `isolatedDeclarations` 特性，并内置了更快的 `bun test` 运行器，测试启动速度比 Jest 快 10 倍。

> 💡 对于想尝试全栈 JavaScript 运行时替代方案的团队，Bun 1.2 的兼容性已足够支撑生产环境。
