# 前端资讯 — 2026-05-09

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. Deno 2.0 候选版本发布：全面兼容 Node.js 生态

**来源：** Deno 官方博客 | [原文链接](https://deno.com/blog/v2.0-rc)

Deno 2.0 RC 版本发布，宣布完全兼容 Node.js 内置模块（`fs`、`path` 等）以及 npm 包管理器。新版本还引入了原生的 `deno compile` 支持，可将 TypeScript 项目直接编译为单文件可执行程序。

> 💡 Deno 2.0 的 Node.js 兼容性意味着开发者可以无缝迁移现有 Express、Next.js 项目，值得关注。


---

## 2. Astro 5.0 发布：内容集合与 Islands 架构重大升级

**来源：** Astro 官方博客 | [原文链接](https://astro.build/blog/astro-5)

Astro 5.0 正式发布，核心更新包括全新的内容集合（Content Collections）API，支持类型安全的 Markdown/MDX 内容管理；以及 Islands 架构的服务器端渲染优化，首屏加载性能提升 30%。

> 💡 对于以内容为中心的网站（博客、文档、电商），Astro 5.0 是目前最值得尝试的静态站点框架。
