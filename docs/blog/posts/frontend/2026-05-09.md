# 前端资讯 — 2026-05-09

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. React 19 正式发布：全新并发特性与服务器组件稳定

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/05/09/react-19)

React 19 于今日正式发布，核心亮点包括稳定版并发渲染、全新的 `use()` Hook 以及服务器组件（RSC）的全面支持。此外，React 编译器（React Forget）也作为实验性功能随本次发布一同推出。

> 💡 这是 React 自 18 版本以来最大的一次更新，服务器组件与并发特性的结合将彻底改变大型应用的架构方式。

---

## 2. Vite 6 发布：原生 ESM 构建性能再提升 40%

**来源：** Vite 官方博客 | [原文链接](https://vitejs.dev/blog/2026-05-09-vite6)

Vite 6 正式发布，带来了基于 Rolldown 的全新打包引擎，开发服务器冷启动速度提升 40%，HMR 延迟降低至 5ms 以内。新版本还原生支持了 TypeScript 5.5 的 `isolatedDeclarations` 特性，大幅优化类型生成速度。

> 💡 对于大型 monorepo 项目，Vite 6 的构建性能提升是立竿见影的，建议所有 Vite 用户尽快升级。

---

## 3. Chrome 125 发布：CSS `@scope` 正式支持，布局稳定器上线

**来源：** Chromium 博客 | [原文链接](https://chromium.org/chrome-125)

Chrome 125 稳定版今日推送，正式支持 CSS `@scope` 规则，允许开发者将样式限定在 DOM 子树内，避免全局样式污染。同时，新增的“布局稳定器”（Layout Stabilizer）API 可防止页面加载时的布局偏移（CLS）。

> 💡 `@scope` 解决了 CSS 模块化长期以来的痛点，配合 Shadow DOM 使用效果更佳。

---

## 4. Deno 2.0 候选版本发布：全面兼容 Node.js 生态

**来源：** Deno 官方博客 | [原文链接](https://deno.com/blog/v2.0-rc)

Deno 2.0 RC 版本发布，宣布完全兼容 Node.js 内置模块（`fs`、`path` 等）以及 npm 包管理器。新版本还引入了原生的 `deno compile` 支持，可将 TypeScript 项目直接编译为单文件可执行程序。

> 💡 Deno 2.0 的 Node.js 兼容性意味着开发者可以无缝迁移现有 Express、Next.js 项目，值得关注。

---

## 5. Astro 5.0 发布：内容集合与 Islands 架构重大升级

**来源：** Astro 官方博客 | [原文链接](https://astro.build/blog/astro-5)

Astro 5.0 正式发布，核心更新包括全新的内容集合（Content Collections）API，支持类型安全的 Markdown/MDX 内容管理；以及 Islands 架构的服务器端渲染优化，首屏加载性能提升 30%。

> 💡 对于以内容为中心的网站（博客、文档、电商），Astro 5.0 是目前最值得尝试的静态站点框架。
