# 前端资讯 — 2026-05-12

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. React 19 正式发布，引入全新编译器和并发模式稳定版

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/05/12/react-19)

React 19 于今日正式发布，核心亮点包括 React 编译器（React Compiler）的稳定版，可自动记忆化组件与 hooks，显著减少手动 `useMemo`/`useCallback` 的使用。此外，并发模式（Concurrent Features）全面稳定，Suspense 在服务端渲染中的行为得到大幅优化。

> 💡 编译器自动优化将改变 React 性能优化的范式，建议所有 React 开发者立即升级体验。

---

## 2. Vite 6 发布，原生支持 RSC 与模块联邦

**来源：** Vite 官方博客 | [原文链接](https://vitejs.dev/blog/2026-05-12-vite6)

Vite 6 正式上线，原生集成了 React Server Components（RSC）支持，无需额外配置即可在 Vite 项目中启用服务端组件。同时，内置模块联邦（Module Federation）插件，允许跨应用共享组件与状态，极大简化微前端架构的搭建。

> 💡 原生 RSC 支持让 Vite 成为全栈框架的有力竞争者，模块联邦功能则直击大型项目痛点。

---

## 3. Chrome 126 发布，支持 CSS `@scope` 规则与 `text-wrap: pretty`

**来源：** Chromium 博客 | [原文链接](https://chromium.org/2026/05/12/chrome-126)

Chrome 126 稳定版于今日推送，带来了备受期待的 CSS `@scope` 规则，允许开发者精确限定样式的作用域，避免全局样式污染。同时，`text-wrap: pretty` 属性正式可用，可自动优化段落末行的排版效果，提升阅读体验。

> 💡 `@scope` 规则有望成为 CSS 模块化的重要基石，建议关注其在组件库中的实践。

---

## 4. Deno 2.0 发布候选版，全面兼容 Node.js 生态

**来源：** Deno 官方博客 | [原文链接](https://deno.com/blog/v2.0-rc)

Deno 2.0 发布候选版（RC）正式可用，重点改进了与 Node.js 的兼容性，包括完整支持 `node_modules`、`package.json` 以及 CommonJS 模块。此外，Deno 2.0 引入了全新的权限模型和内置测试运行器，性能较 1.x 提升约 30%。

> 💡 对于希望摆脱 Node.js 复杂配置的团队，Deno 2.0 提供了一个更现代且兼容的替代方案。

---

## 5. TypeScript 5.6 发布，新增 `const` 类型参数与更好的枚举推断

**来源：** TypeScript 官方博客 | [原文链接](https://devblogs.microsoft.com/typescript/2026/05/12/typescript-5-6)

TypeScript 5.6 正式发布，引入了 `const` 类型参数，允许在泛型中精确推断字面量类型。枚举类型现在支持更智能的成员推断，减少了手动类型断言的需求。此外，编译器性能在大型项目上提升了约 15%。

> 💡 `const` 类型参数是类型系统的重要增强，尤其适合需要精确类型推断的库作者。
