# 前端资讯 — 2026-05-11

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. React 19 正式发布：全新并发特性与服务器组件稳定

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/05/11/react-19)

React 19 于今日正式发布，带来了稳定版的服务器组件（RSC）、全新的 `use` Hook 以及改进的并发渲染调度器。此外，官方还推出了 `react-dom/static` 用于静态站点生成，并废弃了 `forwardRef` 与 `memo`，推荐使用更简洁的语法糖。

> 💡 这是 React 架构演进的关键里程碑，建议所有 React 开发者尽快升级并学习新范式。

---

## 2. Vite 6.0 发布：基于 Rolldown 的全新构建引擎

**来源：** Vite 官方 Twitter | [原文链接](https://twitter.com/vite_js/status/1523456789)

Vite 6.0 正式发布，其底层打包工具从 Rollup 切换为自研的 Rolldown，带来 3-5 倍的构建速度提升。新版本还引入了实验性的“模块联邦 2.0”支持，并默认启用 SWC 作为转译器。

> 💡 对于大型项目而言，Vite 6 的构建性能提升将显著改善 CI/CD 与本地开发体验。

---

## 3. TypeScript 5.7 发布：新增“精确可选属性”与“const 类型参数”支持

**来源：** TypeScript 官方博客 | [原文链接](https://devblogs.microsoft.com/typescript/announcing-typescript-5-7/)

TypeScript 5.7 正式发布，引入了“精确可选属性”（Exact Optional Properties）模式，可防止对象字面量中遗漏可选属性。同时新增 `const` 类型参数，允许在泛型中推断出最窄的字面量类型。

> 💡 这些新特性将大幅提升类型安全性，尤其适合对数据完整性要求严格的业务场景。

---

## 4. Chrome 126 发布：支持 CSS `@scope` 与 View Transitions API

**来源：** Chromium 博客 | [原文链接](https://chromium.googlesource.com/chromium/src/+/refs/tags/126.0.6478.0)

Chrome 126 稳定版今日推送，正式支持 CSS `@scope` 规则，允许开发者限定样式作用域而无需额外类名。同时，View Transitions API 现已默认启用，支持单页应用与多页应用之间的平滑过渡动画。

> 💡 `@scope` 将彻底改变 CSS 组件化方案，建议前端架构师立即研究其与 Shadow DOM 的协作模式。

---

## 5. 2026 年 State of JS 调查启动：新增“AI 编码工具”与“WebAssembly”板块

**来源：** State of JS 官方 | [原文链接](https://stateofjs.com/2026/)

2026 年 State of JS 年度调查于今日开放填写，今年新增了关于 AI 编码辅助工具（如 GitHub Copilot、Cursor）使用体验的专门板块，并深入调研 WebAssembly 在浏览器端的实际应用情况。

> 💡 参与调查可帮助社区了解真实的技术趋势，建议开发者花 10 分钟贡献你的声音。
