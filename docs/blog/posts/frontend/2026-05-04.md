# 前端资讯速览 — 2026-05-04

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. React 19.1 发布：稳定版引入全新并发特性

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/04/29/react-19-1)

React 19.1 于 4 月 29 日正式发布，作为 19 系列的首个稳定小版本，它正式将 `useOptimistic` 和 `useFormStatus` 从实验性标志中移除，并默认启用。此外，新版本优化了 Server Components 的流式渲染性能，大幅减少了首屏加载时的 JavaScript 体积。

> 💡 对于正在迁移到 React 19 的团队，此版本是生产环境升级的稳妥选择。

## 2. Vite 6.0 进入 Beta：原生支持 RSC 与 Rust 插件系统

**来源：** Vite 官方仓库 | [原文链接](https://github.com/vitejs/vite/releases/tag/v6.0.0-beta.0)

Vite 6.0 Beta 版于 5 月 1 日发布，核心亮点是原生支持 React Server Components（RSC），无需额外配置即可与 Next.js 或自定义 SSR 框架集成。同时，新版本引入了基于 Rust 的插件系统（通过 `rolldown` 集成），为大型项目带来 10 倍以上的构建速度提升。

> 💡 这是 Vite 生态迈向全栈构建工具的关键一步，值得关注 RSC 开发体验的团队尽早尝鲜。

## 3. TypeScript 5.7 发布：全新类型收窄与性能优化

**来源：** TypeScript 官方博客 | [原文链接](https://devblogs.microsoft.com/typescript/announcing-typescript-5-7/)

TypeScript 5.7 于 4 月 30 日发布，引入了基于控制流分析的“穷举性检查”增强，能更精确地识别联合类型中的未处理分支。此外，编译器在大型代码库上的类型检查速度提升了约 15%，并修复了长期存在的泛型推断边缘情况。

> 💡 对于追求代码健壮性的团队，新的穷举性检查能有效减少运行时错误。

## 4. Next.js 16 发布：全栈框架迎来“零配置”数据层

**来源：** Vercel 官方博客 | [原文链接](https://nextjs.org/blog/next-16)

Next.js 16 于 5 月 3 日正式发布，最大变化是内置了“数据层”（Data Layer），允许开发者直接在 `app` 目录中使用声明式数据获取语法，无需手动配置缓存或数据库客户端。新版本还默认启用了 Partial Prerendering（PPR），进一步优化了动态内容的加载体验。

> 💡 这是 Next.js 向“全栈元框架”迈出的重要一步，大幅降低了数据获取的复杂度。

## 5. Chrome 125 发布：CSS `@scope` 与 `text-wrap: pretty` 正式可用

**来源：** Chrome 开发者博客 | [原文链接](https://developer.chrome.com/blog/new-in-chrome-125)

Chrome 125 稳定版于 5 月 2 日推送，正式支持 CSS `@scope` 规则，允许开发者更精确地控制组件样式的作用域，避免全局样式冲突。同时，`text-wrap: pretty` 属性也默认启用，可自动优化段落末行的排版，减少孤行和寡字。

> 💡 这两项 CSS 新特性将显著提升组件化开发中的样式隔离与排版质量。
