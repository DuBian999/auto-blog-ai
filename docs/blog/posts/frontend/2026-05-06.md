# 前端资讯 — 2026-05-06

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. React 19 正式发布：全新并发特性与服务器组件稳定

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/05/06/react-19)

React 19 于今日正式发布，带来了稳定版的并发渲染（Concurrent Features）和 React Server Components（RSC）。新版本还引入了 `use()` 钩子用于在组件中直接处理 Promise，并优化了 Suspense 的边界行为。

> 💡 这是 React 架构演进的重要里程碑，RSC 的稳定将彻底改变前后端协作模式。

---

## 2. Vite 6 发布：原生 ESM 构建提速 40%，支持 Rust 插件

**来源：** Vite 官方博客 | [原文链接](https://vitejs.dev/blog/2026-05-06-vite6)

Vite 6 正式上线，核心构建引擎全面转向基于 Rolldown（Rust 实现），开发服务器冷启动时间缩短 40%。新版本还引入了实验性的 Rust 插件 API，允许开发者用 Rust 编写高性能构建插件。

> 💡 对于大型项目团队，Vite 6 的 Rust 插件生态将显著降低构建瓶颈。

---

## 3. Chrome 125 默认启用 CSS `@scope` 规则，样式隔离进入原生时代

**来源：** Chromium 博客 | [原文链接](https://chromium.googlesource.com/chromium/src/+/main/docs/scope-css.md)

Chrome 125 稳定版今日推送，默认开启 CSS `@scope` 规则支持。开发者无需借助 CSS Modules 或 Shadow DOM，即可通过 `@scope (.card) { ... }` 实现基于 DOM 树的样式隔离。

> 💡 原生 CSS 作用域方案将大幅降低样式冲突维护成本，值得所有前端工程师关注。

---

## 4. Next.js 16 进入 Beta：全新 App Router 2.0 与 Partial Prerendering

**来源：** Vercel 官方博客 | [原文链接](https://nextjs.org/blog/next-16-beta)

Next.js 16 Beta 发布，引入 App Router 2.0 架构，支持更细粒度的 Partial Prerendering（PPR）策略。新版本还改进了 Turbopack 的 HMR 稳定性，并内置了与 React 19 的深度集成。

> 💡 对于使用 Next.js 的团队，PPR 的改进将显著提升混合渲染场景下的用户体验。

---

## 5. ESLint 9 正式发布：扁平化配置成为默认，性能提升 2 倍

**来源：** ESLint 官方博客 | [原文链接](https://eslint.org/blog/2026/05/06/eslint-v9.0.0)

ESLint 9 稳定版今日上线，`eslint.config.js` 扁平化配置文件正式成为默认选项。新版本移除了所有已弃用的规则，并重写了核心解析器，lint 速度提升 2 倍以上。

> 💡 这是 ESLint 历史上最大的破坏性更新，建议所有项目在升级前仔细迁移配置文件。
