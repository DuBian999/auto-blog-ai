# 前端资讯 — 2026-05-02

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. React 19 正式发布：全新并发特性与服务器组件稳定

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/04/29/react-19)

React 19 于 4 月 29 日正式发布，带来了稳定版的并发渲染、自动批处理、以及内置的服务器组件支持。新版本还引入了 `use()` 钩子用于在客户端直接消费 Promise，大幅简化数据获取逻辑。

> 💡 这是 React 自 18 以来最大的一次架构升级，建议所有项目尽早规划迁移。

---

## 2. Vite 6 发布：原生 ESM 构建提速 40%，支持 Rspack 插件

**来源：** Vite 官方博客 | [原文链接](https://vitejs.dev/blog/2026/04/30/vite-6)

Vite 6 在 4 月 30 日发布，核心构建引擎重写为基于 Rust 的 Rolldown，冷启动和热更新速度提升显著。新版本还兼容 Rspack 插件生态，开发者可无缝切换构建工具。

> 💡 对于大型项目，Vite 6 的构建性能提升将直接缩短 CI 流水线时间。

---

## 3. Chrome 125 稳定版发布：新增 CSS `light-dark()` 与 View Transitions API

**来源：** Chromium 博客 | [原文链接](https://blog.chromium.org/2026/05/chrome-125-stable.html)

Chrome 125 于 5 月 1 日推送，原生支持 CSS `light-dark()` 颜色函数，开发者无需媒体查询即可实现主题切换。同时，View Transitions API 正式稳定，支持 SPA 和 MPA 间的平滑页面过渡动画。

> 💡 这两个特性将大幅降低暗色模式与页面过渡动画的实现成本。

---

## 4. TypeScript 5.7 发布：支持 `using` 声明与精确可选属性

**来源：** TypeScript 官方博客 | [原文链接](https://devblogs.microsoft.com/typescript/announcing-typescript-5-7/)

TypeScript 5.7 于 4 月 28 日发布，引入了 `using` 声明（基于 TC39 Stage 3 的显式资源管理提案）和精确可选属性类型。新版本还改进了对 `--moduleResolution bundler` 的推断能力。

> 💡 `using` 声明让资源管理更安全，尤其适合文件句柄、数据库连接等场景。

---

## 5. Next.js 16 进入 RC 阶段：全栈 React 19 与 Turbopack 默认启用

**来源：** Vercel 官方博客 | [原文链接](https://nextjs.org/blog/next-16-rc)

Next.js 16 RC 于 5 月 1 日开放测试，默认集成 React 19 并启用 Turbopack 作为开发构建器。新版本还引入了 `app` 路由下的 Streaming SSR 优化，首字节时间（TTFB）平均降低 30%。

> 💡 如果你正在使用 Next.js 14/15，建议立即试用 RC 版本以提前适配。
