# 前端资讯 — 2026-05-13

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. React 19 正式发布：全新编译器与并发特性全面落地

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/05/13/react-19)

React 19 于今日正式发布，核心亮点是内置了 React Forget 编译器，能够自动记忆组件与 hooks，大幅减少手动 `useMemo` 和 `useCallback` 的使用。此外，并发模式（Concurrent Features）现已稳定，包括 `useTransition`、`useDeferredValue` 以及 Suspense 的服务器端渲染支持。

> 💡 这是 React 自 18 版本以来最重要的架构升级，建议所有团队尽快评估迁移计划。

---

## 2. Vite 6.0 发布：基于 Rolldown 的极速构建引擎

**来源：** Vite 官方博客 | [原文链接](https://vitejs.dev/blog/2026-05-13-vite6)

Vite 6.0 正式发布，其底层打包工具从 Rollup 切换为自研的 Rolldown，实现了开发与生产构建的统一。新版本在大型项目上的冷启动速度提升 3 倍，HMR 延迟降低至 10ms 以内，并且原生支持 TypeScript 5.5 的 `isolatedDeclarations` 特性。

> 💡 对于使用 Vite 的中大型项目，升级到 Vite 6 可以显著改善开发体验和构建效率。

---

## 3. TypeScript 5.6 发布候选版：引入“精确可选属性”检查

**来源：** TypeScript 官方仓库 | [原文链接](https://devblogs.microsoft.com/typescript/announcing-typescript-5-6-rc/)

TypeScript 5.6 RC 发布，新增“精确可选属性（Exact Optional Properties）”模式，在 `--exactOptionalPropertyTypes` 选项下，`undefined` 不再被隐式视为可选属性的合法值。此外，还改进了对装饰器元数据（Decorator Metadata）的支持，并优化了类型推断性能。

> 💡 该特性有助于捕获更多潜在的类型错误，建议在严格模式项目中开启体验。

---

## 4. Chrome 125 稳定版：新增 CSS `@scope` 规则与 View Transitions API

**来源：** Chrome 开发者博客 | [原文链接](https://developer.chrome.com/blog/new-in-chrome-125)

Chrome 125 稳定版正式支持 CSS `@scope` 规则，允许开发者将样式限制在特定 DOM 子树内，无需依赖 BEM 或 CSS Modules。同时，View Transitions API 在跨文档导航中默认启用，可实现流畅的页面过渡动画。

> 💡 `@scope` 有望改变组件化样式的编写方式，值得前端架构师深入研究。

---

## 5. Astro 4.5 发布：集成 Server Islands 与内容集合增强

**来源：** Astro 官方博客 | [原文链接](https://astro.build/blog/astro-450/)

Astro 4.5 推出 Server Islands 功能，允许在静态页面中嵌入动态交互组件，实现“静态优先、动态按需”的渲染模式。此外，内容集合（Content Collections）新增对 JSON 和 YAML 数据源的支持，并改进了图片优化管线。

> 💡 Server Islands 为内容型网站提供了兼顾性能与交互的新范式，适合博客、文档站等场景。
