## 1. TypeScript 5.6 发布候选版：引入“精确可选属性”检查

**来源：** TypeScript 官方仓库 | [原文链接](https://devblogs.microsoft.com/typescript/announcing-typescript-5-6-rc/)

TypeScript 5.6 RC 发布，新增“精确可选属性（Exact Optional Properties）”模式，在 `--exactOptionalPropertyTypes` 选项下，`undefined` 不再被隐式视为可选属性的合法值。此外，还改进了对装饰器元数据（Decorator Metadata）的支持，并优化了类型推断性能。

> 💡 该特性有助于捕获更多潜在的类型错误，建议在严格模式项目中开启体验。

## 2. Astro 4.5 发布：集成 Server Islands 与内容集合增强

**来源：** Astro 官方博客 | [原文链接](https://astro.build/blog/astro-450/)

Astro 4.5 推出 Server Islands 功能，允许在静态页面中嵌入动态交互组件，实现“静态优先、动态按需”的渲染模式。此外，内容集合（Content Collections）新增对 JSON 和 YAML 数据源的支持，并改进了图片优化管线。

> 💡 Server Islands 为内容型网站提供了兼顾性能与交互的新范式，适合博客、文档站等场景。
