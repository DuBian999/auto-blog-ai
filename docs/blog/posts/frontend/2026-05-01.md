## 1. Bun 1.2 发布：原生支持 TypeScript 5.6 与 Node.js 兼容性再升级

**来源：** Bun 官方博客 | [原文链接](https://bun.sh/blog/bun-v1.2)

Bun 1.2 正式发布，新增对 TypeScript 5.6 的完整支持，并大幅改进了与 Node.js 核心模块的兼容性，包括 `fs`、`net` 和 `http2` 的 API 对齐。此外，Bun 的包管理器现在支持 pnpm 的 `--frozen-lockfile` 模式。

> 💡 对于追求极速开发体验的团队，Bun 1.2 的兼容性改进使其成为 Node.js 的可靠替代方案。
