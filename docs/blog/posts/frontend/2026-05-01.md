# 前端资讯 — 2026-05-01

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. React 19 正式发布：全新并发特性与服务器组件稳定

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/04/30/react-19)

React 19 于 4 月 30 日正式发布，带来了稳定的并发渲染引擎、全新的 `use()` Hook 以及服务器组件（RSC）的正式支持。此外，Suspense 边界的行为得到优化，数据获取与流式渲染的集成更加无缝。

> 💡 这是 React 自 18 以来最大的一次架构升级，建议所有 React 项目尽快评估迁移计划。

---

## 2. Vite 6 发布：原生 ESM 构建提速 40%，支持 Rspack 插件

**来源：** Vite 官方博客 | [原文链接](https://vitejs.dev/blog/2026/04/30/vite-6)

Vite 6 通过全新的模块图缓存机制和优化后的依赖预构建，冷启动速度提升 40%。同时，Vite 6 引入了对 Rspack 插件的兼容层，允许开发者无缝复用生态中的 Rust 构建插件。

> 💡 对于大型 monorepo 项目，Vite 6 的构建性能提升尤为显著，值得立即升级。

---

## 3. Chrome 126 将默认启用 CSS `@scope` 规则，样式隔离进入新阶段

**来源：** Chromium 博客 | [原文链接](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/docs/security/scope.md)

Chrome 126 计划于 5 月中旬发布，届时将默认启用 CSS `@scope` 规则。该规则允许开发者定义样式的作用域边界，无需依赖 Shadow DOM 或 CSS Modules 即可实现组件级样式隔离。

> 💡 这是 CSS 原生样式隔离的重要里程碑，将显著降低大型应用中的样式冲突问题。

---

## 4. Next.js 16 进入 RC 阶段：新增 Partial Prerendering 与 Turbopack 稳定

**来源：** Vercel 官方博客 | [原文链接](https://nextjs.org/blog/next-16-rc)

Next.js 16 发布候选版本，核心亮点包括 Partial Prerendering（PPR）的稳定化，允许页面中同时包含静态与动态内容。此外，Turbopack 在开发和生产构建中均已达到生产就绪状态，冷构建速度提升 5 倍。

> 💡 PPR 的稳定标志着 Next.js 在混合渲染模式上迈出了关键一步，适合内容型与交互型并存的复杂页面。

---

## 5. Bun 1.2 发布：原生支持 TypeScript 5.6 与 Node.js 兼容性再升级

**来源：** Bun 官方博客 | [原文链接](https://bun.sh/blog/bun-v1.2)

Bun 1.2 正式发布，新增对 TypeScript 5.6 的完整支持，并大幅改进了与 Node.js 核心模块的兼容性，包括 `fs`、`net` 和 `http2` 的 API 对齐。此外，Bun 的包管理器现在支持 pnpm 的 `--frozen-lockfile` 模式。

> 💡 对于追求极速开发体验的团队，Bun 1.2 的兼容性改进使其成为 Node.js 的可靠替代方案。
