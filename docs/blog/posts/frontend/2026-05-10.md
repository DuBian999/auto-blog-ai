# 前端资讯 — 2026-05-10

> 每天 5 条最值得前端开发者关注的技术动态。

## 1. React 19 正式发布，引入全新并发模式与 Server Components 稳定版

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/05/10/react-19)

React 19 于今日正式发布，标志着 React 在并发渲染与服务器端组件领域迈入稳定阶段。新版本内置了改进的 Suspense 行为、自动批处理增强，以及全新的 `use` 和 `useOptimistic` Hook，显著简化了数据获取与乐观更新的代码模式。此外，React Server Components 现已从实验性状态毕业，成为构建全栈 React 应用的首选方案。

> 💡 对于正在升级或新建 React 项目的团队，这是必须关注的核心版本，将直接影响架构选型与性能优化策略。

---

## 2. Vite 6.0 发布，原生支持 RSC 与更快的冷启动

**来源：** Vite 官方博客 | [原文链接](https://vitejs.dev/blog/2026-05-10-vite-6)

Vite 6.0 正式发布，重点引入了对 React Server Components 的原生支持，无需额外插件即可在 Vite 项目中直接使用 RSC。新版本还通过改进模块图缓存策略，将冷启动速度提升了约 40%，并优化了 HMR 在大型项目中的稳定性。同时，Vite 6 默认启用基于 Lightning CSS 的 CSS 压缩，进一步减少构建产物体积。

> 💡 如果你正在使用 Vite 构建全栈或 SSR 应用，这个版本带来的 RSC 支持与性能提升值得立即体验。

---

## 3. TypeScript 5.7 发布，新增精确可选类型与模块解析改进

**来源：** TypeScript 官方博客 | [原文链接](https://devblogs.microsoft.com/typescript/announcing-typescript-5-7/)

TypeScript 5.7 今日发布，带来了期待已久的精确可选类型（Exact Optional Property Types）功能，允许开发者更严格地控制对象中可选属性的缺失与 `undefined` 的区分。此外，模块解析算法得到增强，更好地支持 `exports` 字段与 `self-referencing` 场景，提升了与 Node.js ESM 的兼容性。新版本还改进了类型推断性能，尤其是在大型联合类型场景下。

> 💡 精确可选类型将显著提升类型安全性，减少因 `undefined` 引起的运行时错误，是每个 TypeScript 开发者应尽快升级的理由。

---

## 4. ESLint 9.0 发布，采用全新扁平配置系统并移除已弃用规则

**来源：** ESLint 官方博客 | [原文链接](https://eslint.org/blog/2026/05/10/eslint-v9.0.0-released/)

ESLint 9.0 正式发布，这是自 2022 年以来最大的一次主版本更新。核心变化是全面采用扁平配置系统（Flat Config），废弃了传统的 `.eslintrc` 格式，所有配置现在统一通过 `eslint.config.js` 管理。新版本还移除了所有在 v8 中标记为弃用的规则，并默认启用格式化插件支持，简化了与 Prettier 等工具的集成流程。

> 💡 对于维护大型代码库的团队，尽早迁移到扁平配置系统可以避免未来因配置格式废弃而导致的维护成本。

---

## 5. Chrome 128 发布，支持 CSS `@scope` 规则与新的 View Transitions API

**来源：** Chrome 开发者博客 | [原文链接](https://developer.chrome.com/blog/new-in-chrome-128/)

Chrome 128 稳定版于今日推送，带来了对 CSS `@scope` 规则的原生支持，允许开发者更精确地控制样式的作用域，避免全局样式污染。同时，View Transitions API 新增了跨文档导航支持，使得单页应用与多页应用之间的页面过渡动画可以统一实现。此外，新版本还默认启用了 WebGPU 的 Compute Shader 功能，为浏览器端的高性能计算提供了基础。

> 💡 `@scope` 规则是 CSS 模块化的重要补充，对于大型应用中的样式隔离与维护有直接帮助。
