# 前端资讯 — 2026-05-08

> 每日精选 5 条前端领域最新动态，助你把握技术脉搏。

## 1. React 19 正式发布：全新并发特性与 Server Components 稳定

**来源：** React 官方博客 | [原文链接](https://react.dev/blog/2026/05/08/react-19)

React 19 于今日正式发布，带来了稳定的 Server Components、改进的并发渲染调度器以及全新的 `use()` Hook。新版本还引入了自动批处理优化，大幅提升了大型应用的渲染性能。

> 💡 这是 React 架构演进的重要里程碑，建议所有 React 开发者尽快升级体验。

---

## 2. Vite 6.0 发布：原生 ESM 构建提速 40% 并支持 Rspack 插件

**来源：** Vite 官方博客 | [原文链接](https://vitejs.dev/blog/2026-05-08-vite6)

Vite 6.0 正式上线，核心构建引擎全面转向 Rust 重写的 Rolldown，冷启动和热更新速度提升显著。新版本还引入了对 Rspack 插件的兼容层，降低了迁移成本。

> 💡 对于追求极致构建性能的团队，Vite 6 是当前最值得尝试的构建工具。

---

## 3. Chrome 126 发布：CSS `@scope` 规则正式可用

**来源：** Chromium Blog | [原文链接](https://chromium.org/blog/2026-05-08-chrome-126)

Chrome 126 稳定版今日推送，默认启用了 CSS `@scope` 规则，允许开发者精确控制选择器的作用域范围。该特性与 `:has()` 选择器结合，可大幅简化组件样式隔离的实现。

> 💡 这是原生 CSS 模块化的重要进步，有望减少对 CSS-in-JS 方案的依赖。

---

## 4. Next.js 17 进入 RC 阶段：引入部分预渲染与新的数据流模式

**来源：** Vercel 官方博客 | [原文链接](https://nextjs.org/blog/2026-05-08-nextjs-17-rc)

Next.js 17 候选版发布，核心亮点是部分预渲染（PPR）的稳定化，允许页面混合静态与动态内容。同时，新的 `stream()` API 简化了服务端数据流的处理逻辑。

> 💡 对于使用 Next.js 的团队，PPR 特性将显著改善动态页面的加载体验。

---

## 5. Bun 1.2 发布：原生支持 TypeScript 5.7 并内置 Tailwind CSS 处理

**来源：** Bun 官方博客 | [原文链接](https://bun.sh/blog/2026-05-08-bun-1.2)

Bun 1.2 版本发布，成为首个原生支持 TypeScript 5.7 装饰器与 `using` 声明的运行时。新版本还内置了 Tailwind CSS 的 JIT 编译能力，无需额外配置即可使用。

> 💡 Bun 正在快速缩小与 Node.js 的生态差距，是值得关注的下一代运行时。
