## 1. Shopify 收购 Tailwind CSS

**来源：** Hacker News | [原文链接](https://tailwindcss.com/blog/tailwind-is-joining-shopify)

Tailwind CSS 官方宣布被 Shopify 收购，Tailwind 团队将加入 Shopify 继续维护和发展该框架。Tailwind 是当前最流行的原子化 CSS 框架之一，被大量前端项目采用，此次收购意味着其未来发展方向和商业模式可能发生变化。

> 💡 Tailwind CSS 被收购是前端生态的重大事件，直接影响数百万使用该框架的开发者，需关注后续开源策略和维护计划是否变化。

## 2. React 19.3 发布：View Transitions、Fragment Refs 等新特性

**来源：** React Official | [原文链接](https://react.dev/blog/2026/09/09/react-19-3)

React 19.3 正式发布，新增 View Transitions、Fragment Refs、browser() API、Trusted Types 等特性。View Transitions 让页面过渡动画更原生流畅，Fragment Refs 解决了长期存在的 ref 转发痛点，这些更新对日常 React 开发有直接影响。

> 💡 React 是前端最核心的框架，每次版本更新都会影响大量项目的开发方式和最佳实践。
