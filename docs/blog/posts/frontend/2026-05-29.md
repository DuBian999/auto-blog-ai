**来源：** Tailwind CSS Official | [原文链接](https://tailwindcss.com/blog/tailwindcss-v4-3)

## 5. Endive：一个基于 JVM 的原生 WebAssembly 运行时

**来源：** Hacker News | [原文链接](https://github.com/bytecodealliance/endive)

Bytecode Alliance 开源了 Endive，这是一个在 JVM 上原生运行的 WebAssembly 运行时。它允许在 Java 生态中直接执行 Wasm 模块，为跨语言互操作和边缘计算提供了新可能。

> 💡 WebAssembly 是前端技术栈向服务端和边缘场景扩展的关键技术，Endive 打通了 JVM 与 Wasm 的桥梁，对全栈和微服务架构有潜在影响。
